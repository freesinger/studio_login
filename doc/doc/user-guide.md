# Studio Login 使用手册

Studio Login 是 LAS Studio 的企业账号和用量管理入口。管理员在这里维护 Studio 连接、资源配置、子账号、价格和账单；企业子账号登录后选择有权限的 Project，再进入 Studio。

本文面向日常使用人员，不包含安装部署和接口联调步骤。部署说明见仓库根目录的 `README.md`，双服务联调说明见 `doc/studio-login-integration-test-manual.md`。

## 1. 角色与功能范围

| 角色 | 可用功能 |
| --- | --- |
| 系统管理员 | 企业概览、Studio 连接、资源配置组、企业子账号、价格配置、模型统计和账单；可查看内部成本 |
| 企业子账号 | 登录后选择已授权的 Project，并在新窗口进入 Studio |

系统管理员账号由部署配置提供。管理员创建的普通业务账号均为企业子账号。

## 2. 推荐的首次配置顺序

管理员首次使用时，按下面的顺序操作：

1. 登录 Studio Login。
2. 在企业概览中新增 Studio 服务连接，等待状态变为已连接。
3. 新建资源配置组，填写 Project、资源凭证和月度共享上限。
4. 系统管理员按需配置客户单价和内部成本单价。
5. 创建企业子账号，为账号授权一个或多个配置组。
6. 使用子账号登录，确认能够看到并打开对应 Project。
7. 任务运行后，在模型统计和账单中核对用量、金额与任务状态。

资源配置组依赖可用的 Studio 连接，子账号又依赖已经生效的配置组，所以不建议跳过前面的步骤。

## 3. 登录和语言切换

打开部署方提供的 Login 地址后，输入登录账号、密码和图形验证码。右上角可以切换中文、English 或日本語。

![登录页](images/user-guide/01-login.png)

登录时需要注意：

- 图形验证码有效期为 2 分钟，只能提交一次。验证失败或过期后，点击换一张再试。
- 管理员登录后进入管理工作台，企业子账号登录后进入 Project 选择页。
- 会话有效期为 7 天。停用账号或主动退出后，现有会话会失效。
- 连续输错或短时间请求过多会触发 10 分钟窗口的频率限制。遇到请求过于频繁时，请停止重试并稍后再登录。
- 当前没有自助找回密码入口。子账号忘记密码时，由管理员在企业子账号模块中修改。

## 4. 企业概览和 Studio 连接

企业概览展示当前配置组数、子账号数、本月任务数、本月应收和 Studio 服务连接状态。

![企业概览](images/user-guide/02-overview.png)

### 4.1 新增连接

点击新增 Studio 服务连接，填写：

- 连接名称：便于管理员区分不同 Studio 实例。
- Studio 公网地址：用户进入 Studio 和 Login 调用 Studio 接口时使用。
- Login 公网地址：Studio 回调 Ticket 校验和用量接口时使用。

![新增 Studio 服务连接](images/user-guide/11-create-studio-connection.png)

点击保存并注册后，Login 会向 Studio 注册 Ticket 回调，并读取部署 Region 和计费目录。连接卡片显示已连接后，才能用它创建配置组。

生产环境中的两个地址都应使用公网 HTTPS 地址。不要填写带用户名、密码、查询参数或 URL 片段的地址。

Integration Token 和 App ID 由部署环境提供，所有连接复用当前 Login 的这组服务凭证。页面不会要求用户输入或展示 Integration Token。

### 4.2 编辑、重试和删除

- 编辑：修改连接名称或服务地址，并重新注册。
- 重试注册：连接状态为失败时显示，用于重新发起注册。
- 删除：只有在没有非删除配置组引用该连接时才允许执行。

如果保存后一直未连接，先检查两个公网地址能否双向访问，再核对 Studio 是否已经为当前 App ID 启用 Integration Token。

## 5. 资源配置组

资源配置组把一个 Studio 连接、一个 Project 和一套资源凭证组合在一起。组内子账号共享配置组月度上限。

![资源配置组](images/user-guide/03-resource-groups.png)

卡片中可以查看：

- 配置是否已经生效。
- 所属 Studio 连接和 Region。
- 资源配置来自 Studio 远端还是本地缓存。
- 已配置的凭证数量。
- 月度共享上限、已结算、执行中预冻结和当前可用额度。
- 同 Project 数据共享是否开启。

可用额度按下面的口径计算：

```text
当前可用额度 = 月度上限 - 已结算金额 - 执行中预冻结金额
```

未填写月度上限时表示不限额。账期按部署时区的自然月计算。

### 5.1 新建配置组

点击新建配置组，选择 Studio 连接，并填写配置组名称。当前配置组名称同时作为 Studio Project ID 使用，创建后不能在页面中修改。

![新建资源配置组](images/user-guide/10-create-resource-group.png)

必填资源配置包括：

- LAS API Key
- Ark API Key
- Bucket

可以选择两种录入方式：

1. 手动填写：适合只配置必填凭证和少量自定义模型。
2. 从 JSON 导入：粘贴 Studio 设置导出的完整 JSON。Login 会提取资源和自定义模型字段，Region 与 TOS Region 仍以所选 Studio 连接返回的部署信息为准。

自定义模型为可选项。添加后按表单选择模型类型、填写模型 ID、Base URL 和 API Key，并可以先测试连通性再保存。

点击保存并生效后，系统会：

1. 加密保存资源配置。
2. 注册当前 LAS API Key 对应的用量回调。
3. 把 Project 资源配置同步到 Studio。
4. 把新版本同步到已绑定的子账号。

编辑配置组会生成一个内部版本并立即发布。历史任务继续使用创建任务时保存的配置和价格快照。

### 5.2 默认配置组和数据共享

- 默认配置组会在创建子账号时优先选中，也会作为子账号的默认 Project。
- 开启数据共享后，同一 Project 的子账号按共享模式使用资源数据。
- 数据共享一旦开启就不能关闭。如需改为隔离模式，应新建配置组后重新分配子账号。

### 5.3 同步失败

配置组出现部分同步失败时，卡片会列出失败账号、错误信息和 Request ID。确认 Studio 已恢复后，点击重试同步。

有关联子账号的配置组不能直接删除。先把这些子账号迁移到其他配置组或删除账号，再删除配置组。

## 6. 企业子账号

企业子账号模块用于创建业务账号、分配 Project、设置个人额度和控制登录状态。

![企业子账号列表](images/user-guide/04-subaccounts.png)

列表按配置组展示每个账号的个人额度、已结算、预冻结和可用额度。一个账号绑定多个配置组时，每个配置组分别显示一行额度数据。

子账号的实际可用额度同时受两层限制：

1. 该账号在当前配置组中的个人月度上限。
2. 当前配置组的月度共享上限。

其中任一层额度不足，Studio 的新任务预检都会被拒绝。

### 6.1 创建子账号

点击创建子账号后：

1. 选择一个或多个配置组。
2. 为每个配置组设置子账号月度上限，留空表示不设个人上限。
3. 选择一个默认配置组。
4. 填写显示名称、登录账号和初始密码。
5. 点击创建账号。

![创建企业子账号](images/user-guide/05-create-subaccount.png)

密码长度为 12 到 128 位，必须同时包含大写字母、小写字母、数字和特殊字符。登录账号创建后不能修改。

创建成功后，系统会把该账号在各个 Project 中的资源 Profile 同步到 Studio。同步失败时，列表会显示具体配置组和错误信息，可从账号操作菜单中重试。

### 6.2 日常账号操作

点击每行右侧的 `…` 菜单，可以执行：

- 编辑显示名称、密码、配置组授权和额度。
- 停用或恢复账号。停用会立即使现有登录会话失效。
- 重试失败的 Studio Profile 同步。
- 删除账号。历史任务和账单仍会保留。

列表中的查看密码会显示当前子账号密码。只应由获授权的管理员在必要时使用，不要截图、复制到工单或通过普通聊天发送。

### 6.3 CSV 批量导入

点击下载 CSV 模板，按模板填写后使用 CSV 导入。子账号模板列为：

```csv
loginName,displayName,password,configGroup,monthlyLimit
```

CSV 每行只绑定一个配置组。需要为同一账号授权多个配置组时，先导入账号，再在页面中编辑授权。

导入按行处理，部分行失败不会回滚成功行。完成后应查看导入结果中的失败行和原因。

## 7. 价格配置

价格配置仅系统管理员可见。它用于维护各计费项的客户价格和内部成本。两者默认按用量单价计费。`las_llm...` 和自定义语言模型生成的 `request` 计费项还可以根据 Studio 上报的 `BillingContext` 分别计算客户金额和内部成本。

![价格配置](images/user-guide/06-pricing.png)

选择作用范围后，可以新增、编辑、停用或批量导入价格：

- 配置组价格：只对选中的配置组生效。
- 平台默认：配置组没有单独价格时使用。
- 内置默认：平台和配置组都没有配置时使用部署内置值。

价格匹配顺序为：

```text
配置组价格 > 平台默认价格 > 部署内置默认价格
```

价格最多支持 10 位小数。修改价格只影响之后创建的任务，历史任务继续使用创建时的价格快照。删除操作会停用当前价格记录，后续任务将回退到下一层可用价格。

对于 `las_llm...` 和自定义语言模型的 `request` 计费项，客户价格和内部成本各有一组计价模式页签，两者可独立配置：

- 按用量单价：金额等于 `Usage × 单价`。
- 按 BillingContext 公式：直接使用 `BillingContext` 字段路径，公式结果就是该计费项本次产生的客户金额或内部成本，不再乘 `Usage`。

公式支持数字、字段访问、括号和 `+ - * /` 四则运算。例如：

```text
(prompt_tokens - prompt_tokens_details.cached_tokens) * 0.002
  + prompt_tokens_details.cached_tokens * 0.0002
  + completion_tokens * 0.001
```

公式直接从根字段开始，不需要添加 `a.` 或 `BillingContext.` 前缀。客户价格和内部成本公式共用一份测试数据，例如：

```json
{
  "total_tokens": 15958,
  "prompt_tokens": 15116,
  "completion_tokens": 842,
  "prompt_tokens_details": {
    "audio_tokens": null,
    "cached_tokens": 4920,
    "provisioned_tokens": null,
    "audio_cached_tokens": null
  },
  "completion_tokens_details": {
    "reasoning_tokens": 0,
    "provisioned_tokens": null
  }
}
```

点击校验并试算后，页面会同时计算当前启用公式模式的客户金额和内部成本。系统会检查 JSON、公式语法、引用字段和结果。字段值为 `null` 时按 `0` 计算；字段缺失、引用非数字字段、除以零、负数或超出金额范围都会校验失败。公式计价任务会在创建时保存公式和预估金额，完成时再用实际 `BillingContext` 结算。

`BillingContext` 由 Studio 的用量上报接口发送。不同算子的字段可能不同，例如语言模型通常包含 `prompt_tokens`、`completion_tokens` 和缓存 Token 明细。配置公式前应使用该计费项的真实上报样本试算，不要假设所有计费项都有同一组字段。

部分自定义语言模型在预估阶段只上报 `request_count`，真实 Token 字段在任务完成后才出现。预估上下文缺少公式字段时，系统使用该价格记录中的单价快照预冻结客户额度和估算成本，实际回调再使用公式结算。实际上下文字段异常时也会回退到任务创建时的单价快照，并记录告警，避免任务长期占用预冻结额度。

价格列表在公式模式下只显示“公式计价”徽标。将鼠标悬停在徽标上，或使用键盘将焦点移到徽标，可以查看对应的客户价格公式或内部成本公式。其他计费项继续使用原有的客户单价和内部成本单价界面，不显示公式配置区域。

价格 CSV 模板列为：

```csv
billingItemId,unit,customerPricingMode,customerUnitPrice,customerPriceFormula,costPricingMode,costUnitPrice,costPriceFormula
```

导入前先在页面选择作用范围。计费项和单位必须与 Studio 返回的计费目录或当前自定义模型目录一致。
公式列只对支持 BillingContext 公式的计费项生效。`customerPricingMode` 和 `costPricingMode` 可填 `UNIT` 或 `FORMULA`；填 `FORMULA` 时必须填写对应公式，填 `UNIT` 时会清空对应公式并按单价计费。模式列留空但公式列有值时按公式导入；模式列和公式列都留空时保留已有公式配置。旧四列 CSV 仍可导入，只更新单价且不会清空已有公式。

## 8. 模型统计

模型统计按日期和计费项查看任务调用、用量与金额，适合排查单个任务或核对某段时间的消费。

![模型统计](images/user-guide/07-model-usage.png)

可以按以下条件筛选：

- 开始日期和结束日期，单次查询最多 90 个自然日。
- 明细或汇总。
- 计费项、配置组、子账号和任务状态。

明细模式展示任务时间、计费项、配置组、子账号、状态、用量和金额。语言模型任务还会显示 Input、Output 和 Cache Token。系统管理员可以看到内部成本。

任务状态包括执行中、成功、失败和已取消。执行中任务超过阈值时，页面还会展示补偿查询状态，帮助判断 Studio 终态回调是否丢失。

有审计记录的任务可以下载 JSON。审计文件可能包含任务请求、结算回调和补偿查询报文，应按内部数据处理，不要上传到公开工单或外部聊天。

## 9. 账单

账单按自然月汇总任务和实际结算金额，适合月度核对。

![账单](images/user-guide/08-bills.png)

可选择的汇总维度包括：

- 整体：按任务状态汇总当前企业。
- 配置组：查看各 Project 的任务数和金额。
- 子账号：查看各账号的任务数和金额。

成功任务计入实际客户金额和内部成本；失败、取消或仍在执行的任务会保留任务数，但实际金额可能为零。系统管理员可以看到内部成本，企业管理员只看到客户金额。

模型统计支持任意日期范围和任务明细，账单按月汇总。排查单个任务时使用模型统计，月度结算时使用账单。

## 10. 企业子账号进入 Studio

企业子账号登录后，页面列出该账号可访问的 Project。可使用搜索框按 Project 或连接名称筛选。

![Project 选择](images/user-guide/09-project-selector.png)

点击 Project 后，Login 会生成一次性 Ticket，并在新窗口打开 Studio。Ticket 有效期为 2 分钟且只能使用一次。当前 Project 选择页会保留，切换 Project 时回到该页面重新选择。

如果点击后没有打开 Studio，请检查浏览器是否拦截了新窗口，并确认对应 Studio 连接和配置组都处于可用状态。

## 11. 常见问题

### 保存 Studio 连接后显示失败

检查 Studio 公网地址和 Login 公网地址是否可以互相访问，并确认生产环境使用 HTTPS。然后在连接卡片上点击重试注册。

### 无法创建资源配置组

至少需要一个已连接的 Studio 服务。确认 LAS API Key、Ark API Key 和 Bucket 已填写，且 Studio 能返回部署 Region。

### 创建子账号后提示同步失败

账号已经保存，但某个 Project 的 Profile 没有同步成功。查看失败配置组和 Request ID，修复 Studio 连接或资源配置后再重试同步。

### 子账号能登录，但看不到 Project

确认账号处于正常状态，至少绑定一个可用配置组，并且对应 Studio 连接已连接。如果列表中有 Project 但进入后资源不可用，继续检查该账号在对应配置组中的 Profile 同步状态。

### 新任务提示额度不足

同时检查子账号在当前配置组中的个人额度和配置组共享额度。执行中任务会占用预冻结金额，直到收到终态回调或补偿查询完成。

### 修改价格后旧任务金额没有变化

这是预期行为。任务创建时会保存价格快照，后续改价不会重算历史任务。
